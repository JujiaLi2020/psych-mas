# Figure inventory

All PNG files in this folder were generated from the saved v0.7.6 evaluated
snapshot using `reproducibility/generate_figures.py` while the current package
was v0.7.7. They are data-derived teaching figures, not screenshots and not
new detector results.

| File | Purpose | Source |
|---|---|---|
| `case_332_performance.png` | Contextual response accuracy and response-time comparison | `session_inputs.json`, 500 x 40 responses and RT rows |
| `case_332_domain_profile.png` | Compact governed domain summary | `case_332/domain_evidence.csv` |
| `case_332_evidence_lineage.png` | Family-level evidence path to priority | `case_332/b3_input.csv`, `case_332/governed_review.csv` |

Recommended export setting is 300 dpi. Captions and interpretation limits are
provided in `../manuscript_ready_materials.md`.
